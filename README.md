# Jewel City Daily Devotional

The static home of the daily devotional of Jewel City Church, Gombe, drawn from the messages preached among us.

- A new edition is published every midnight (West African time).
- All devotional content lives in `devotions.js`, newest entry first. `index.html` features the latest edition; `archive.html` lists every edition.
- Served via GitHub Pages from the `main` branch.
